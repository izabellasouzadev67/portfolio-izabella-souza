# Portfólio Izabella Souza Matos

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Bem-vindo(a) ao portfólio pessoal de Izabella Souza Matos, uma vitrine dinâmica de suas habilidades e projetos em Desenvolvimento Web, Design UI/UX e Suporte Técnico. Este portfólio foi desenvolvido utilizando tecnologias web modernas e princípios de design bem planejados.

## 🚀 Sobre o Projeto

Este portfólio é um projeto pessoal criado com o objetivo de demonstrar as competências de Izabella em desenvolvimento front-end, design UI/UX e suporte técnico. Ele foi construído utilizando HTML5, CSS3 e JavaScript, com o Figma sendo empregado para a criação de protótipos e wireframes.

## ✨ Principais Funcionalidades

*   **Design Responsivo:** Adapta-se perfeitamente a diferentes tamanhos de tela.
*   **Navegação Interativa:** Transições fluidas e um menu intuitivo.
*   **Conteúdo Dinâmico:** Elementos como a saudação personalizada (que varia conforme o horário) na página inicial conferem um toque especial.
*   **Alternância de Tema:** Permite que os usuários alternem entre os modos claro e escuro para uma experiência de visualização mais confortável.
*   **Vitrine de Projetos:** Seção dedicada à exibição de diversos projetos, incluindo detalhes e links.
*   **Formulário de Contato:** Um formulário integrado para facilitar a comunicação.
*   **Formação e Experiência:** Detalhes sobre a trajetória acadêmica e profissional.

## 🛠️ Tecnologias Utilizadas

*   **Frameworks/Bibliotecas:** React (sugerido por certas estruturas de arquivos e potencial integração futura, embora não seja utilizado de forma extensiva no código atual), TypeScript (mencionado na análise, mas não presente explicitamente nos trechos de código)

## 📚 Como Utilizar

Este portfólio funciona como um currículo digital e uma demonstração das habilidades de Izabella. Os usuários podem navegar pelas diferentes seções para conhecer sua trajetória, conferir seus projetos e entrar em contato.
